# How to run?

### STEPS:


### STEP 01-  Create and activate a virtual environment:

```powershell
python -m venv venv
venv\Scripts\activate
```


### STEP 02- install the requirements
```bash
pip install -r requirements.txt
```


```bash
# Finally run the following command
python app/main.py
```

Now,
```bash
open up you local host and port
```
